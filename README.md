# NATO Alphabet 🔤
Python project that converts words into the **NATO phonetic alphabet** using the `pandas` library.

---

## 📖 Description
- Reads a CSV file containing the NATO phonetic alphabet
- Uses Pandas to create a dictionary mapping letters to code words
- Converts user input into a list of phonetic words

---

## 📂 Features
- Clean use of Pandas `DataFrame` and dictionary comprehension
- Interactive input for any word
- Simple and practical demonstration of data handling
